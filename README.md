# CALCULATRICE

A mini calculator in Java, built for the ENI Java OOP course (Module 7 - Exceptions).

## About The Project

The goal is a mini calculator performing addition, subtraction, multiplication, integer division and its remainder. It works with `int` values and must account for integer overflow (which silently wraps without raising an error) and division by zero (which raises an `ArithmeticException`), to avoid displaying a wrong result. Made from scratch following specific instructions. More details are in the [assignment PDF](https://github.com/Dyrits/CALCULATRICE/blob/master/Module%2007%20-%20Enonc%C3%A9%20TP%20-%20Les%20exceptions.pdf).
